# MyLogic Web

MyLogic SV5.1의 원본 심벌 600개와 실습 회로 10개를 사용하는 웹 논리회로 편집기입니다. 원본 폴더와 실행 파일은 수정하지 않았습니다.

## 실행

Windows에서는 `start-web.cmd`를 더블클릭합니다. 또는 이 폴더에서 `node server.mjs`를 실행하고 http://127.0.0.1:5173 에 접속합니다. 의존성 설치나 인터넷 접속 없이 실행할 수 있습니다. 시작 스크립트는 설치된 Node.js 또는 현재 Codex의 번들 Node.js를 사용합니다.

배포 결과: https://mylogic-web.winterisgod0101.chatgpt.site (계정 소유자에게만 접근이 허용되는 비공개 사이트)

## 사용

- 왼쪽 부품을 클릭한 뒤 도면을 클릭해 배치합니다. 검색 및 기본/실습/Spartan/전체 분류를 제공합니다.
- `V`: 선택, 드래그: 이동, `Shift+클릭`: 여러 부품 선택, `Ctrl+A`: 전체 선택.
- `N` 또는 `W`: 배선. 시작 핀 → 경유점 → 도착 핀 순서로 클릭합니다. 기존 배선에 연결하면 분기됩니다. 빈 위치에 끝내려면 더블클릭합니다.
- 원본 단축키: `L/R`: 좌/우 회전, `X/Y`: 좌우/상하 대칭, `Home`: 전체 보기, `F5`: 시뮬레이션, `Ctrl+E`: 회로 검사.
- `Layout` 메뉴에서 선택한 여러 부품을 정렬하고 간격을 맞춥니다.
- `Esc`: 도구 종료, `Delete`: 삭제, `Ctrl+Z/Y`: 실행 취소/다시 실행, `Ctrl+C/V`: 선택 부품 복사/붙여넣기.
- 입력 스위치 또는 입력 포트 더블클릭으로 0/1을 전환합니다. 작은 화면에서는 도면 탭 오른쪽의 **입출력** 버튼으로 패널을 엽니다.
- 계층 부품을 더블클릭하면 내부 원본 회로가 열립니다. 이전 도면으로 돌아가려면 실행 취소합니다.
- `Step`은 CLOCK 입력 패턴을 10 ns씩 실행합니다. 기본 D 플립플롭은 상승 에지에서 D를 저장합니다.
- 진리표(입력 10개까지), 파형(최근 40개 기록), 회로 검사, 7세그먼트 표시를 제공합니다.
- `Ctrl+S`: 웹 회로 JSON 저장. `Ctrl+O`: 웹 JSON 또는 원본 `schematic` 가져오기. File 메뉴에서 SVG 도면과 진리표 CSV를 내보낼 수 있습니다.
- 회로 편집은 브라우저 localStorage에 자동 저장됩니다. 입력 신호와 실행 취소 이력은 세션 상태입니다.
- 입력 설정은 MyLogic `CLOCK`, `MAX_TIME`, `WATCH` 문법을 사용하며 `stim.stm`으로 내보낼 수 있습니다. `GEN`, `VECTOR`는 미지원입니다.

## 원본 데이터와 구현

`scripts/build-data.mjs`가 `../MyLogic`, `../MyLogicSV51/Library/MyLogic`, `../MyLogicSV51/Data/MyLogic/PRM`의 텍스트 데이터를 읽어 `dist/data.json`을 생성합니다. `node scripts/build-data.mjs`로 다시 생성할 수 있습니다. CP949/EUC-KR 텍스트를 읽고 MFFT의 중첩 괄호 형식을 파싱합니다.

심벌은 원본의 선, 원호, 사각형, 텍스트, 포트 좌표로 SVG에 표시합니다. 배선은 끝점과 T 분기에서 연결되며 단순 교차는 서로 다른 넷으로 유지됩니다. 선택한 부품을 이동·회전하면 연결된 배선의 끝점을 함께 갱신합니다. 원본의 중첩 회로는 내부 회로를 재귀적으로 계산합니다.

`scripts/inspect-native.py`는 실행 파일의 PE 메뉴 리소스를 읽습니다. `scripts/native-menus.json`은 원본 스키매틱 편집기의 영어 메뉴 기록입니다. File/Edit/View/Add/Shape/Layout/Tools/Window/Help 구성을 이 기록에 맞췄습니다.

## 검증

```text
node --check dist/app.js
node --test tests/engine.test.mjs
```

9개 테스트가 통과했습니다. 반가산기와 두 전가산기의 모든 입력 조합, 4비트 가산기의 256가지 덧셈, FND의 십진수 패턴, 원본 `mysim.out` 기록과의 대조, T 분기/교차 배선 구분, 미연결 입력, 미지원 모델 및 D 플립플롭 에지를 확인합니다. MySim 기록 대조는 원본 기록의 첫 32개 행 중 이진 신호로 구성된 행을 검사합니다.

브라우저에서 부품 배치, 배선, 실행 취소, 입력 전환, 원본 회로 열기, 진리표 및 Step 파형 표시를 확인했습니다. 작은 화면과 데스크톱 화면을 각각 점검했습니다.

## 현재 재현 범위

원본 프로그램의 완전한 복제본은 아닙니다. 원본 심벌·좌표·회로와 논리 편집/시뮬레이션의 핵심 기능을 구현했습니다. 600개 심벌 중 모든 소자에 시뮬레이션 모델이 있는 것은 아닙니다.

지원 모델은 AND/OR/XOR/NAND/NOR/XNOR, 인버터, 버퍼, 전원, MUX, 기본 FD/FDC/FDP/FDR/FDS/FDE/FDCE 계열 및 첨부된 계층 실습 회로입니다. 미지원 모델과 미연결 입력은 X로 표시하고 회로 검사에 알립니다.

MySim의 지연·타이밍 검사, 버스 폭 연산, 메모리와 모든 순차 소자, HDL 컴파일, EDIF/SPICE, FPGA 배치·배선, 원본 MFFT 파일로 다시 저장하기, 심벌 제작, 도형/문자 편집, 원본 Windows UI의 픽셀 단위 복제는 아직 구현되지 않았습니다. 복사/붙여넣기는 부품만 복사하며 배선은 복사하지 않습니다. 원본 프로그램 화면 캡처는 도구 시간 초과로 검증하지 못했고, 제공된 회로 이미지와 원본 파일/메뉴 리소스로 확인했습니다.

첨부된 FND 회로의 숫자 7은 F 세그먼트를 켭니다. 원본 회로를 변경하지 않고 그 출력도 그대로 재현합니다.
